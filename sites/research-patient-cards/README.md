# База исследования · облачная версия

Приватное приложение Sites: адаптивная форма с семью разделами, постоянное хранение тестовых записей в D1 и скачивание отдельного Excel-документа. Для доступа используется вход в ChatGPT. Отдельный сервер Render и его платный диск для этой версии не нужны. Доступ зависит от работы Sites и действующих лимитов аккаунта; бессрочная доступность без сбоев не гарантируется.

## Как работать

1. Откройте опубликованный адрес на компьютере или iPhone, войдите в тот же аккаунт ChatGPT.
2. Нажмите «Новая запись», введите тестовый код, заполните нужные разделы.
3. Нажмите «Сохранить в приложении». Сохранённые карты доступны с обоих устройств.
4. Чтобы передать записи, нажмите «Скачать Excel». Прикрепите полученный `research-records.xlsx` к чату и попросите перенести данные в исходную исследовательскую книгу.

Автоматической записи в исходную книгу или Google Sheets нет. Выгружается документ с исходными данными на восьми листах, включая отдельный текст рекомендаций врача. Названия столбцов совпадают с исходной книгой. Полная исследовательская книга, расчётные листы и формулы в выгрузку не включаются: при переносе используются исходные листы, а расчётные ячейки исследовательской книги сохраняются.

В форме нет новых полей. Допустимые категории соответствуют исходному файлу и явным уточнениям пользователя. Пустые значения остаются пустыми. Коды диагнозов вводятся свободно. Числа и даты выгружаются типизированными ячейками; произвольный текст не превращается в формулы Excel.

Используются только вымышленные учебные карты из предыдущего MVP. Версия не предназначена для реальных медицинских данных. Исходная Excel-книга не изменяется. Если ранее вы вводили дополнительные записи в Codespaces/Render, они не находятся в репозитории и не переносятся автоматически: сначала скачайте оттуда Excel.

## Разработка

```bash
npm ci
npm run build
npm test
```

`worker/schema.json` — точная копия схемы прежнего приложения; `worker/seed.json` — учебные записи. `worker/index.js` — сервер, `worker/export.js` — создание отдельного XLSX. `drizzle/` содержит только схему базы; исходные учебные записи добавляются приложением один раз и не заменяют существующие записи при обновлении.

`dist/server/index.js` — самостоятельный Worker ESM. `.openai/hosting.json` содержит ID сайта и логическую декларацию D1; реальные ресурсы и HTTPS подключает Sites. Код Python и конфигурация Render сохранены в основном GitHub-репозитории как прежний вариант запуска. Облачная версия лежит отдельно в `sites/research-patient-cards/`.

При одновременном редактировании одной карты сохраняется последняя подтверждённая версия. Выгрузка включает все сохранённые карты; несохранённые изменения формы в неё не входят. Регулярно скачивайте Excel как резервную копию.
