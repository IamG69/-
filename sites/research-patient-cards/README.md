# База исследования · GitHub Pages

Статическое адаптивное приложение с семью разделами, локальным хранением записей в браузере и скачиванием отдельного Excel-документа. Сервер и вход в аккаунт для работы не требуются. Версия предназначена для GitHub Pages и не зависит от домена `chatgpt.site`.

## Как работать

1. Откройте опубликованный адрес в браузере рабочего компьютера.
2. Нажмите «Новая запись», введите тестовый код, заполните нужные разделы.
3. Нажмите «Сохранить в приложении». Запись останется только в этом браузере и профиле пользователя.
4. Чтобы передать записи, нажмите «Скачать Excel». Прикрепите полученный `research-records.xlsx` к чату и попросите перенести данные в исходную исследовательскую книгу.

Автоматической записи в исходную книгу или Google Sheets нет. Выгружается документ с исходными данными на восьми листах, включая отдельный текст рекомендаций врача. Названия столбцов совпадают с исходной книгой. Полная исследовательская книга, расчётные листы и формулы в выгрузку не включаются: при переносе используются исходные листы, а расчётные ячейки исследовательской книги сохраняются.

Не очищайте данные сайта в браузере и не используйте приватное окно: это удалит или изолирует локальные записи. Регулярно нажимайте «Скачать Excel» и сохраняйте файл как резервную копию. Другой компьютер или другой профиль браузера эти записи не увидит.

В форме нет новых полей. Допустимые категории соответствуют исходному файлу и явным уточнениям пользователя. Пустые значения остаются пустыми. Коды диагнозов вводятся свободно. Числа и даты выгружаются типизированными ячейками; произвольный текст не превращается в формулы Excel.

Используются только вымышленные учебные карты из предыдущего MVP. Версия не предназначена для реальных медицинских данных. Исходная Excel-книга не изменяется. Если ранее вы вводили дополнительные записи в Codespaces/Render, они не находятся в репозитории и не переносятся автоматически: сначала скачайте оттуда Excel.

## Разработка

```bash
npm ci
npm run build:pages
npm test
```

`worker/schema.json` — точная копия схемы прежнего приложения; `worker/seed.json` — учебные записи. `worker/local-api.js` — локальное хранилище IndexedDB; `worker/export.js` — создание XLSX непосредственно в браузере. Команда `npm run build:pages` создаёт готовый сайт в `docs/`.

Прежние варианты для Python/Render и Sites сохранены в репозитории, но для GitHub Pages не используются. Готовая статическая версия лежит в `sites/research-patient-cards/docs/` и публикуется отдельной веткой `gh-pages`.

Выгрузка включает все сохранённые в текущем браузере карты; несохранённые изменения формы в неё не входят.
